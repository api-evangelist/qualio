# Qualio

> Qualio is an AI-powered quality management system (QMS) and compliance platform for life sciences companies (medical devices, pharma, biotech, SaMD, CROs). Its Developer API provides secure, programmatic access to documents, quality events, training, users, suppliers, design controls, change management and compliance intelligence.

Authentication: API key via the `X-Api-Key` header. Generate a Developer API token in the Qualio admin panel (Admin Settings > Developer API tokens); admin privileges required. Base URL: https://api.qualio.com (RESTful v1). A prior GraphQL API at api.app.qualio.com/pa is deprecated.

## APIs
- [Qualio Developer API](https://developer-portal.qualio.com/): OpenAPI 3.1.0, 56 paths / 132 operations across 11 domains.
